# Time-series analysis assignment

Python solutions to the PHYS4143 time-series assignment and all five extra ideas.

- [Main assignment](main_notes.ipynb): harmonic spectra, solar oscillations, Procyon weights and spectral windows with observing gaps.
- [Supplementary theory](THEORY.md): spectral normalization, sampling and aliases, window functions, statistical weights, and mode coherence.
- [Extra ideas](extra_ideas_notes.ipynb): star03 CLEAN, solar high-pass filters, three solar band-pass reconstructions, CLEAN band-pass filtering, and weighted 46 LMi CLEAN with a scatter/noise comparison.

The notebooks include saved results and figures. The `.py` files are the source-code appendix. Equations use double-dollar display math.

## Run

Use Python 3.11 or later from this directory:

```bash
python -m pip install -r requirements.txt
python download_data.py
python run.py
jupyter lab main_notes.ipynb extra_ideas_notes.ipynb
```

`run.py` recalculates the main assignment and all five extras in dependency order. It takes several minutes. To run only the main assignment, use `python main_analysis.py`. Individual extras are implemented in the five `extra_*.py` files; run `extra_solar_modes.py` before `extra_clean_modes.py`.

In each notebook, `RUN_ANALYSIS = False` displays the saved results. Change it to `True` and run all cells to recompute that notebook's analysis after downloading the data. Running a script updates the figures and result files; rerun the notebook cells to refresh its displayed outputs.

## Software use

`time_series.py` provides the spectrum and spectral-window functions, with frequencies in microhertz:

```python
from time_series import spectrum, spectral_window

result = spectrum(time_days, velocity, frequencies_uhz, time_unit="d")
window = spectral_window(time_days, frequencies_uhz, 1000.0, time_unit="d")
```

Pass `weights=weights` for statistical weighting. Power is fitted amplitude squared. For a known zero baseline, use `center=False`. The command-line interface exports a spectrum to CSV and accepts frequency limits and spacing; run `python time_series.py --help` for its options. The analysis scripts produce the assignment plots.

## Data and source

Observations come from [D. Stello's course data directory](https://www.physics.usyd.edu.au/~stello/timeseries/). Exact URLs, column meanings and file checksums are in [data/source_manifest.json](data/source_manifest.json). The downloader checks all four inputs. Procyon's third column is already a statistical weight; 46 LMi uses inverse-square scatter weights, with its absolute error scale tested in Extra 5.

Methods and exercise prompts follow D. Stello, *PHYS4143 Time Series Lecture 1* (2026), PDF pages 61–65, including the Frandsen et al. (1995), A&A 301, 123, Section 4.2 prescription reproduced there. Lecture PDFs and downloaded input files are not included. Large intermediate CSVs are regenerated by the scripts and excluded from Git.
